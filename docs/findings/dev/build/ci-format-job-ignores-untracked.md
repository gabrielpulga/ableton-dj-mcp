title: ci-format-job-ignores-untracked

## Fact

CI's Format job runs `npm run format` (writes) then `git diff --exit-code`,
which only detects changes to already-tracked files. A prettier misconfig that
breaks formatting of gitignored-but-still-globbed files (e.g. generated build
artifacts) passes CI green even though `npm run format:check` (used locally and
in `npm run check`) fails on the same files.

## Evidence

PR #234 broke `.prettierignore` resolution for `src/generated/*` (gitignored,
regenerated by `npm run build-info` which the Format job runs first). CI's
Format job stayed green because those files are untracked, so `git diff` never
saw them. The bug was only caught by running `npm run format:check` directly in
a later session.

## Apply when

Trusting a green CI Format job as proof formatting is fully correct — it isn't,
for any file matched by prettier's globs but excluded from git tracking. Run
`npm run format:check` directly for a true signal.
